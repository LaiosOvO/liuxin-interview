    ## 架构对称性补充说明

    | 维度 | HumanNode | AutoNode |
    |------|-----------|----------|
    | 节点函数内 | `interrupt(payload)` 等人工决策 | 直接执行业务逻辑 |
    | 触发路径 | 外部 API `POST /actions` → `NodeService.submit_action` | LangGraph 调度直接到节点函数 |

    | actor | 人工传入（li.si / hr.alice 等） | 固定 `system:auto` |
    | action 类型 | ADVANCE / RETURN / REJECT | SYSTEM |
    | 失败补偿 | `action_logs.failed` + `recover_from_db.py` | 同左 |
    | 幂等 | upsert（PG ON CONFLICT） | 同左 |
